Privacy Policy — README Injector

Last updated: October 13, 2026

README Injector is a Chrome extension that prepends or appends markdown snippets to your GitHub repository READMEs. This policy explains what it does with your data, in plain terms: it keeps everything on your device.

Data stored on your device

  • Your GitHub personal access token, which you paste into the extension yourself. It is kept in the extension's local storage (chrome.storage.local) so you don't have to re-enter it.
  • Your extension preferences (e.g. snippet text, prepend/append choice).

Data sent to GitHub

To do its job, the extension talks to the GitHub API (api.github.com) using your token. It only ever:

  • Lists your repositories, so you can pick which ones to update.
  • Reads README files from the repositories you select.
  • Commits README updates that you explicitly approve.

What is never collected or shared

  • Your token, repositories, and README contents are never sent to us or any third party. We never see any of it.
  • No analytics, no tracking, no crash reporting, no ads.
  • The token pre-fill helper on GitHub's token pages only fills in form fields (name, expiration, scopes). It never reads or transmits the token GitHub generates — you copy that yourself.

Deleting your data

  • Click Forget in the extension popup to delete the stored token from your device.
  • Uninstalling the extension removes all of its locally stored data.

Changes to this policy

If this policy changes, the new version will be posted here and the extension's store listing will be updated.
